## 📁 Featured Projects  

- [**Fact-Checked Ad Copywriter**](https://github.com/Gaurav9693089415/fact-checked-ad-copywriter) – AI-powered system that extracts factual claims from product pages, verifies them using trusted sources, and generates credible, persuasive ad copy.  

- [**AI HiringAgent**](https://github.com/Gaurav9693089415/HiringAgent-AI---A-crew-of-AI-agents-hiring-smarter-) – Agentic AI-powered app that automates resume screening, requirement scraping, and interview scheduling using specialized AI agents for smarter hiring.  

- [**RAG-Powered Internal Docs Chatbot**](https://github.com/Gaurav9693089415/rag-internal-docs-chatbot) – Streamlit chatbot for querying internal documents using GPT-3.5 and FAISS vector search, built with LangChain and OpenAI API.  

- [**DeepSeek R1 Fine-Tuned for Medical Diagnostics**](https://github.com/Gaurav9693089415/AI-Medical-Chatbot) – LLM-based clinical QA system fine-tuned using Unsloth and LoRA adapters on the Medical-O1 dataset for domain-specific diagnostic reasoning.  

- [**Face Age & Gender Detection**](https://github.com/Gaurav9693089415/face-age-gender-detection) – Deep learning model using PyTorch, OpenCV, and Gradio to predict age and gender from facial images, integrated with DVC for dataset and model versioning.  

- [**AQI Predictor**](https://github.com/Gaurav9693089415/AQI-Predictor) – Python-based air quality forecasting system using SARIMAX models and STL decomposition for accurate AQI predictions.  

- [**ISRO HelpBot**](https://github.com/Gaurav9693089415/ISRO-HelpBot) – AI-powered assistant for retrieving ISRO knowledge using Knowledge Graphs, NLP, and semantic search — built for ISRO Bharatiya Antariksh Hackathon 2025.
